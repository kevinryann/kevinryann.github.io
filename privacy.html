Hydra privacy policy

Last updated: 25 October 2026

Hydra is a private assistant used only by its owner. It has no other users.

What data Hydra accesses

With the owner's explicit consent through Google sign-in, Hydra accesses the owner's Google Calendar (read and write), Gmail (read-only) and Google Contacts (read-only).

How the data is used

The data is used only to answer the owner's requests and to manage the owner's own calendar. It is not sold, shared with third parties, or used for advertising.

Where the data is stored

Sign-in tokens and any cached data are kept only on the owner's private home server, readable only by the owner's account.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions, after which Hydra can no longer read any Google data.

Google API Services User Data Policy

Hydra's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
